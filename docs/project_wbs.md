# 如是项目 WBS、进度与下一步计划

更新日期：2026-11-15（日本时间）。范围：以《金刚经》为第一本材料，建立依据用户认可老师讲解的可追溯数据、首次参数微调和独立评估流程。

当前阶段：**工程环境与全文来源准备已完成；尚未形成合格训练样本，尚未进行参数训练。** 已机械整理第四分4条原话问答候选；当前最需要推进的是人工审核和训练用途确认。

用户已确认后续顺序：3～5条问答验证审核流程 → 小批SFT → 独立题集前后比较 → 检索基线 → RAFT对照；准入与交付物见[分阶段实验](experiments/staged_training.md)。

## 1. 目标与执行约定

第一轮交付目标：从真实老师讲解形成经审核、可训练的问答，完成一次可复现的 LoRA/QLoRA 微调，并用独立题集比较同一基座加载与不加载适配器的表现。结果允许是改善、不变或退步，均须保留证据。

- 经文用于核对原句与版本；经义答案依据用户认可老师的实际讲解，不让 AI 按字面自行解释。
- 用户认可的优先老师为南怀瑾老师、星云大师、杨宁老师；《金刚经》首轮以星云大师《金刚经讲话》两册为主线，不混合讲法。
- AI 负责来源检索、机械提取、对齐、候选问题整理、工程实现和记录；用户或用户指定审核人负责经义、讲解归属及样本批准。
- 训练使用依据与内容审核分别记录。AI 不替代权利方授予许可，也不自行替人工填写批准。
- 低负担推进，不设强制完工日期；按交付物与准入条件推进，不用训练分数代替理解或修证。

负责人栏为建议分工，未任命任何外部人员。状态含义：“已完成”仅针对该行交付物；“待确认”依赖人工判断或外部使用依据；“未开始”不表示已授权自动越过前置条件。

## 4. 主要课题与处理办法

| 编号 | 课题／当前问题 | 影响 | 处理办法与关闭条件 | 优先级 |
| --- | --- | --- | --- | --- |
| K01 | 训练使用范围尚未确认 | 正式训练与发布准入未满足 | 分别核实经文、讲解用途；留存书面依据，不能仅以公开可读或非商业目的代替确认 | P0 |
| K02 | 第四分4条机械选段候选尚未人工核对 | 尚无合格训练内容 | 审核本机候选包，核对问题、上下文、归属与编辑后再扩展 | P0 |
| K03 | 经义审核责任人尚未具体安排 | 无人可以真实完成内容批准 | 由用户自行审核或指定认可的审核人；AI不自任证悟或经义裁判 | P0 |
| K04 | 经文与讲解底本存在版本差异 | 可能误判错引或改坏老师原话 | 保留双方版本；逐项复核22分差异，分别记录原文与讲解归属 | P1 |
| K05 | 模型会编造出处 | 现成模型回答不能直接成为标准答案 | 用真实来源构建引用判分规则；后续增加出处一致性检查，缺证据时留待核实 | P1 |
| K06 | 缺乏真正独立题集 | 无法判断训练是否改善行为 | 用老师讲解确定判分依据；历史开发题移出正式测试；分组检查跨章节重复 | P1 |
| K07 | 只有推理验证，未做本机训练 | 无法保证当前模型与参数能在24GB内稳定微调 | 准入满足后小批量、短上下文试跑，测实际内存与截断，不先扩大模型 | P1 |
| K08 | 训练/评估/检索仅有部分工具与预留包 | 不能把目录存在当作功能已实现 | 先补工作单转合格样本、正式评测入口；检索和Agent待首轮闭环后推进 | P2 |

K05依据为[历史小段实验](experiments/diamond_pilot.md)中实际输出；该实验的AI拟答已撤回，不能再用作经义依据或独立测试。

## 5. 下一步计划

按依赖推进，不设硬性日期。单次可按约30分钟安排，未完成的任务顺延，不为赶进度降低审核要求。

| 顺序 | 下一项行动 | 预期交付物 | 前置条件／决策点 |
| --- | --- | --- | --- |
| N1 | 明确审核人及使用范围；整理需向权利方确认的问题 | 审核分工与用途清单；已有许可依据的归档 | 用户决定审核安排；外发询问须另有明确指示，不自动联系他人 |
| N2 | 从第4分做小批老师讲解选段与问答整理 | 建议先形成3—5条待审问答，每条有实际原话和精确定位 | 以实际讲解为据；数量仅供安排，不强凑；保持候选状态 |
| N3 | 用第1分检验带版本差异材料的处理方式 | 至少一份完整的差异核对与编辑记录示例 | N2流程明确；不混用两种底本 |
| N4 | 确认工作单到reviewed的转换、审核记录和评测题格式 | 可重复的整理步骤或工具；不合格记录能被拦截 | 样本格式和审核口径确定；不把机械提取当成人工批准 |
| N5 | 依同样方法逐分扩展全经 | 32分处理状态清单及实际合格样本清单 | 许可确认与人工审核持续推进；无合适答案的项目保留待补或排除 |
| N6 | 确认首轮数据规模、分组划分并封存测试题 | 训练/验证/测试首版、数据快照与正式评测基线 | 达到M2；测试判分依据经核对，历史开发题不冒充独立题 |
| N7 | 进行首次小规模微调与加载验证 | 首个适配器、日志、配置、资源记录 | 达到M3，来源与内容均满足准入 |
| N8 | 完成人工盲评与迭代复盘 | 对比报告、错误清单、下一轮明确改动 | 达到M4；允许出现不改善或退步结果 |

N1的确认和资料整理、N2/N3的候选准备、N4的工程完善可以并行推进；正式训练必须等待许可、内容与数据准入条件满足。此处“并行”指工作安排，不表示启用多代理。
