# 经义学习必须依据老师讲解

生效日期：2026-11-08。依据：项目发起人在会话中明确要求，不能让 AI 按字面自行解释经文；优先采用其认可、重视实修实证的老师之讲解。本约定优先于早期文档中允许 AI 拟写经义答案再审核的做法。

## 1. 来源选择

目前用户指定的优先老师为南怀瑾老师、星云大师、杨宁老师。此名单记录用户的选材认可，不能由程序推导为“已经核实证悟”或“全佛教一致公认”的客观标签。AI 不负责判定个人修证境界，也不按知名度、学历、头衔或理论著述数量自动增加老师。

优先查找老师本人讲授、经审定出版的讲记、所属机构或可靠出版方的资料。转载、第三方朗读与 AI 配音必须另行标记，不能冒充本人开示。新增讲者先由用户决定。

## 2. 原文与解释的分工

- 经文原文用于逐字核对引文、版本、经名、译者和卷页，不单凭字面生成经义解释。
- 经义与修行指导以指定老师的实际讲解为依据，保留解释归属和上下文。
- AI 可以检索、定位、转录、排版、对齐经文和讲解、整理候选问题，不自行补写老师未讲过的意思。
- 参考答案优先采用可定位的讲解摘录。需要删节、简繁转换或重排时记录变更，并由人工逐条核对；不擅自将多位老师的观点合成新结论。
- 只有原文、没有相应讲解时，登记“待补讲解”，不生成释义占位答案用于训练。
- 测试题的经义判分依据同样来自老师讲解，不由 AI 自拟“标准答案”；引用定位题可直接依据文献元数据。

## 3. 每条经义候选必须记录

除现有审核字段外，补充：

| 字段 | 内容 |
| --- | --- |
| answer_basis | 经义为 teacher_commentary；仅文献事实为 source_metadata；未补齐时为 pending_teacher_commentary |
| teacher | 老师姓名，与用户认可名单和实际作品一致 |
| commentary_source_url | 实际讲解的链接，不是仅有经文的链接 |
| commentary_locator | 书名、版次及页码/段落，或视频起止时间戳 |
| commentary_excerpt | 经核对的实际讲解摘录，不填 AI 拟造的话 |
| review_notes | 核对人、日期、编辑动作及不确定事项 |

老师讲解与经文本身的许可分别记录。找到书目或公开视频不等于已取得训练使用权，也不等于已核对相应段落。

导出工具已拦截缺少讲解依据的经义类记录，即使误标 approved/permitted 也不能直接导出。字段无法自动证明讲解真实或无增义，仍需人工核对。source_metadata 仅适用于文献事实，不能用来规避经义审核。
