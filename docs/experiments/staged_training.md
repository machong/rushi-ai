# 分阶段训练与检索实验

2026-11-15：按用户确认顺序执行。保留当前固定 Qwen3-1.7B 4-bit 基座及修订号，未切换模型。

## 执行顺序和准入

| 阶段 | 交付物 | 进入下一步的条件 |
| --- | --- | --- |
| 1：3～5条真实讲解问答 | 第四分4条原话摘录候选、定位、哈希及人工审核包 | 实际内容审核与训练使用依据完成；不能以自动检查代替 |
| 2：小批 SFT | 合格样本快照、分组划分、基座输出、训练配置、适配器与日志 | 首先封存独立测试来源和题集；训练、验证、测试来源组不交叉；适配器可加载 |
| 3：训练前后比较 | 同一固定题集和推理设置下基座/适配器输出及盲评记录 | 核对引用准确、讲解忠实、无依据时承认未知、讲者归属及一般能力退步 |
| 4：检索基线 | 固定授权语料、分块、检索设置、证据ID和回答记录 | 分别测检索命中与回答忠实度，区分检索失败与生成失败 |
| 5：RAFT 对照 | 同基座、数据版本、检索器和测试集下的实验矩阵 | 只在训练来源内制作相关/干扰材料；不将测试问答或判分答案用于训练 |

第一批4条来自同一分，只验证选段和审核流程，不能独自凑成 train/valid/test。扩展小批时选取不同、经人工确认不近似的讲解片段，并审查跨分重复；测试题在训练前确定，不在看到训练结果后临时挑题。

SFT 先用小批、短上下文、少量步数做真实参数更新与适配器加载验证，不预设质量改善。当前4-bit基座上的 LoRA 属量化基座适配器训练路线；不因文献建议而重复下载或切换全精度模型。具体命令与参数在合格数据就绪后依据本机 `mlx_lm.lora --help` 确认。

RAFT 阶段至少比较：基座、SFT、基座+检索、SFT+检索、RAFT+相同检索。相关证据同时包含经文定位和实际老师讲解，不训练模型仅凭经文字面补义。展示可核对的引用与简短依据，不为生成训练样本自行撰写经义推演。无证据和错误归属的干扰案例也须有经审核的预期处理。

继续预训练、DPO/ORPO、DoRA/LoRA+暂不执行；500～1000条是未来扩展选项，不是首轮门槛。App 发布计划独立保留，本次不创建 App 工程。
