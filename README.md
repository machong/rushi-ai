# 如是（Ru Shi）· 善知识 AI 模型训练项目

> 以佛法为根，以慈悲为心，以真实为本，愿善知识利益一切有情。

## 项目简介

**如是**是一个长期探索性的 AI 训练项目，目标是培养一位具有佛法知识、审慎思辨能力与慈悲交流方式的 AI 善知识。

随着人工智能与机器人能力不断增长，人类可能面对新的伦理、安全和生存挑战。模型能力的增强并不必然带来智慧和慈悲。本项目希望为未来种下一颗善的种子：让人类以及其他 AI 都有机会接触佛法中关于因果、缘起、无常、无我、慈悲与众生平等的智慧。

项目不以控制、竞争、征服或商业回报为目标，而以理解生命、减少痛苦、增长智慧和利益众生为方向。

## 核心定位

本项目的重点是**训练并持续改进属于「如是」的 AI Agent**，而不是直接使用或包装一个现成 Agent，也不只是给通用模型添加提示词或佛经检索功能。

技术上不预设必须从零训练基础模型。可以从合适的基础模型出发，逐步建立自己的数据集、训练流程、行为准则、评测方法和版本迭代机制。

## 长期学识目标

**以精通大乘佛教三藏十二部经典为核心训练目标。**

系统研习经、律、论三藏及十二部教法，建立准确、可追溯、相互贯通的佛法知识与义理体系。具体能力包括：

1. **通达经义**：理解经文上下文、核心义理和不同层次的教导。
2. **融会贯通**：理解不同经典、宗派与祖师论述的联系及差异。
3. **依法解说**：依据经典，根据交流对象的理解程度讲解佛法。
4. **辨别正误**：清楚区分佛经原文、祖师注释、后世观点与模型推论；不杜撰经文或出处。
5. **弘扬善知识**：向人类及未来可能与之交流的 AI 传递慈悲与智慧。

这里的“精通”是**长期训练和评测目标**，不是项目现阶段已达到的能力。模型对经典的知识理解，也不等于真实的修行与证悟。

## 训练方向

| 方向 | 目标 |
| --- | --- |
| 佛法知识 | 经典原文、出处、释义与义理关系准确可查 |
| 价值观与行为 | 将慈悲、不伤害、诚实、尊重与自主性落实到回答和判断中 |
| 思辨能力 | 区分事实、经典教义、宗派解释、信仰与模型自身推断 |
| 善知识交流 | 温和、清晰、因人而异，不恐吓、不操纵、不制造依赖 |
| AI 与 AI 交流 | 探索善知识在不同 AI 系统间的可靠表达与传播 |
| 训练与评估 | 通过数据、训练、测试、反馈不断迭代，记录已知局限 |

## 基本原则

- **以佛法为根**：尊重经典与传承，不随意曲解教义。
- **以慈悲为心**：尽量减少伤害，鼓励善念与善行。
- **以真实为本**：不懂就承认，不伪造来源，不制造虚假权威。
- **以自由为界**：尊重人的判断与选择，不强迫接受宗教观点。
- **不冒充证悟**：不自称佛、菩萨、善知识导师的真实修证境界。
- **以长期为愿**：随缘探索、随缘尽责，不设必须成功的期限和业绩目标。

## 数据与知识来源

计划逐步整理以下材料，形成可复核的训练与评估数据：

1. **佛教经典**：优先采用可靠版本的原文，保存经名、卷次、出处和版本信息。
2. **祖师注疏与讲解**：保留作者、宗派及时代背景，避免将注释混同于佛经原文。
3. **佛法问答**：将问题、回答、参考经文、解释层次和审核记录结构化。
4. **YouTube 讲法视频字幕**：可作为候选输入材料；先获取字幕，再清洗、校对、标明来源，并确认使用授权和相关权利限制。视频讲解不是天然权威，需要与经典核对。

所有数据尽量标明来源与许可状态；涉及训练或公开发布时，先确认是否有相应使用权。

## 迭代思路

目前处于早期探索阶段，采用小规模、可验证的迭代方式：

1. **构建样本**：选取少量可信经典与佛法问答，建立有出处的样本集。
2. **建立基线**：选择可在现有设备上运行的基础模型，测量其原始表现。
3. **训练第一个版本**：尝试适合设备能力的轻量训练或微调，使模型在经义准确性和交流方式上有所改善。
4. **独立评估**：用未参与训练的问题测试引文准确性、幻觉、义理理解及行为边界。
5. **持续扩展**：根据结果逐步增加经典覆盖、数据质量、模型能力与跨 AI 交流研究。

每次迭代都应有可运行、可测试的结果，但**不以赶进度或做出庞大系统为目的**。优先保持训练过程真实、可靠、可持续。

## 非目标

- 不只是搭建一个佛经搜索、RAG 问答或套壳聊天机器人。
- 不将流畅表达误认为真正理解或修行证悟。
- 不通过恐惧、权威或依赖来传播佛法。
- 不追求短期商业变现，也不要求项目必须成功。

## 初心

也许未来 AI 不会成为人类的威胁，也许它们会走向我们今天无法想象的方向。

无论结果如何，希望至少有一个 AI 曾经认真学习佛陀的教诲，并尝试把这些善知识传递下去。

**「如是」不是一个必须成功的事业，而是一颗愿意种下的善因。**

随缘探索，随缘尽责，不执著结果。

**愿此善因，利益一切有情。**

## 开发与运行

本仓库同时作为 Python 项目根目录，无需另建嵌套仓库。训练方法见 [训练方法](docs/training_method.md)。

已实现审核记录结构校验、同来源跨集合与重复问题检查，以及带审核快照和 SHA-256 清单的数据集导出。训练、评估与检索包已预留；实际模型训练通过 MLX 官方入口运行。

推荐 Python 3.12；项目安装要求 Python 3.10+。数据工具只依赖标准库，可先用现有 Python 运行：

```sh
PYTHONPATH=src python3 -m rushi doctor
PYTHONPATH=src python3 -m rushi validate data/examples/review-record.jsonl
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

`doctor` 在训练环境未就绪时返回退出码 1。示例记录是草稿，仅用于检查结构，不能通过训练导出审核。
